## API Overview

### Core Quantization Functions

```c
// Initialization
int quant_init(void);
void quant_cleanup(void);

// INT8 Quantization
int quant_float32_to_int8(const float* input, int8_t* output, 
                          size_t size, quant_stats_t* stats);
int quant_int8_to_float32(const int8_t* input, float* output, 
                          size_t size, const quant_stats_t* stats);

// Per-channel Quantization
int quant_weights_per_channel_int8(const float* input, int8_t* output,
                                   uint32_t rows, uint32_t cols, 
                                   quant_stats_t* stats);

// FP16 Quantization
int quant_float32_to_float16(const float* input, uint16_t* output, 
                             size_t size);
int quant_float16_to_float32(const uint16_t* input, float* output, 
                             size_t size);

// Calibration
calibration_context_t* quant_calibration_create(uint32_t max_samples, 
                                                size_t sample_size);
int quant_calibration_add_data(calibration_context_t* ctx, 
                               const float* data, size_t num_elements);
int quant_calibration_compute_stats(calibration_context_t* ctx, 
                                    float percentile);
void quant_calibration_destroy(calibration_context_t* ctx);

// Model Quantization
int quant_quantize_model(const char* input_model, const char* output_model,
                        quantization_type_t quant_type, 
                        const char* calibration_data);
int quant_evaluate_accuracy(const float* original_output,
                           const float* quantized_output, size_t size,
                           float* mae_out, float* rmse_out);
```

## Script Usage Examples

### Whisper Quantization
```bash
python3 scripts/quantize_whisper.py \
    --model openai/whisper-base \
    --output models/whisper_int8.m2bn \
    --quantization int8 \
    --evaluate
```

### MT Model Quantization
```bash
python3 scripts/quantize_mt_model.py \
    --model VincentChelsea/IndicTrans2-en-ta \
    --output models/indicTrans2_int8.m2bn \
    --quantization static_int8 \
    --calibration-texts calibration.txt \
    --benchmark
```

### TTS Quantization
```bash
python3 scripts/quantize_tts_model.py \
    --model models/hifigan.pt \
    --model-type hifigan \
    --output models/hifigan_stream.m2bn \
    --quantization streaming \
    --benchmark
```

### Master Orchestrator
```bash
python3 scripts/quantize_all.py \
    --output-dir models/quantized \
    --device cuda
```
